Every protocol with no token yet — ranked by what its launch would be worth.

How a launch is valued

implied value = TVL × category multiple × growth × maturity × breadth

The multiple is not a guess: it is the live market's own median market-cap-per-dollar-of-TVL for that category, read out of this snapshot's protocols that already trade. A category with fewer than five live protocols falls back to the whole market's median. Growth is the protocol's own seven-day TVL change, clamped to −60%…+120% and weighted by one half. Maturity is how long it has run with no token (0.60 at day zero, rising to 1.00 at three years). Breadth adds 5% per extra chain, up to four. No protocol name is ever special-cased — the same function scores every row.

An implied value is this radar's own claim, never a promise: it says what a token would be worth if the protocol's record stayed as it is. It does not predict whether or when a token is issued. A protocol is shown as recording no token when its DefiLlama record carries none — the record is not proof, and it may still hold one.
